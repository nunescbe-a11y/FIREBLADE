# Fireblade Update — Customer Call Recording Capture

See GitHub issue #2.

This update is a **data-capture foundation only**. Do not add transcription, summarization, sentiment, lead extraction, coaching, or analytics yet.

## Functional goal
Capture and retain customer-call recordings generated by marketing employees, link them to the existing Fireblade call records, and make recording availability/status visible to admins.

## Required data
For each recording preserve:
- Fireblade call ID
- employee ID
- device ID
- customer number
- incoming/outgoing direction
- SIM/line
- call start/end timestamps
- call duration
- recording start/end timestamps
- recording source/capability mode
- recording/consent status
- MIME type
- file size
- SHA-256 checksum
- private storage path
- upload state / retry state
- failure reason

## Storage
Use private storage only. Never expose public recording URLs. Audio and metadata must remain separable so future processing can be added later without changing the capture pipeline.

## Android requirements
- Recording must be visible to the employee and implemented with appropriate consent/notice.
- Do not bypass Android security/privacy controls.
- Do not use AccessibilityService to record remote call audio.
- Detect whether the specific device/OEM supports usable call audio capture.
- Return a clear UNSUPPORTED state when two-sided capture is unavailable.
- Preserve the current call-collector workflow.

## Web requirements
Add recording status/availability to the call detail/admin view, but no analysis UI yet.

## Backend requirements
Add authenticated upload handling with resumable/retry-safe behavior, dedupe via call ID + checksum, and private object storage.

## Testing
Start with one company test phone. Verify linkage, audio quality, both sides where supported, offline retry, duplicates, permissions, storage privacy, and regression safety.

## Important blocker
The Android source is not yet in this repository. Add `Android_Call_Collector/` before implementation. Exclude generated build folders and secrets.
